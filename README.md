# Adarsh Bal Vidya Mandir Junior High School Website

A modern, responsive website for Adarsh Bal Vidya Mandir Junior High School, showcasing the school's features, mission, and contact information.

## 🌟 About the School

Adarsh Bal Vidya Mandir is a government-recognized junior high school located in Dariyabad, Barabanki, Uttar Pradesh. The school is committed to providing quality education with a focus on holistic development, combining modern teaching methods with strong moral values.

### Key Features

- **Qualified & Experienced Teachers**: Dedicated faculty with deep expertise
- **Smart Classes**: State-of-the-art classrooms with computer education
- **Holistic Development**: Focus on academic, social, and personal growth
- **Home Study Monitoring**: Consistent follow-up on student progress
- **Skill Development Programs**: Extra classes for practical skills
- **Religious & Cultural Activities**: Promotion of moral values and cultural awareness
- **Free Health Checkups**: Regular medical checkups for student well-being
- **Transport Facility**: Safe and reliable school transportation

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for structure
- **CSS3**: Custom styling with CSS variables and animations
- **JavaScript**: Scroll reveal animations and interactivity
- **Google Fonts**: Baloo 2 and Nunito fonts for typography

## 📱 Features

- Fully responsive design
- Smooth scrolling navigation
- Animated hero section with gradient backgrounds
- Statistics showcase
- Feature cards with hover effects
- Principal introduction section
- Call-to-action for admissions
- Contact information and location details

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

1. Clone or download this repository
2. Navigate to the project directory
3. Open `index.html` in your web browser

No additional setup or dependencies required - this is a static website!
